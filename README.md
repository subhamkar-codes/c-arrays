# C Arrays

Programs covering arrays in C — from basics to pointers and memory layout.

## Files

| File | Concept |
|---|---|
| `01_array.c` | Array basics — declaration and initialization |
| `02_array_input.c` | Taking array input from user via scanf |
| `03_other_ways_2init_array.c` | Different ways to initialize arrays |
| `04_pointer_in_array.c` | Using pointers to access array elements |
| `05_arrays_in_memory.c` | How arrays are stored in memory |
| `06_array_using_pointer.c` | Traversing arrays using pointer arithmetic |
| `07_array2D.c` | 2D arrays — declaration, input, and traversal using nested loops |

## Concepts covered
- Array declaration, initialization, and indexing
- Array-pointer relationship
- Memory layout of arrays
- 2D arrays and nested loop traversal
